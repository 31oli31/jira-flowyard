Christmas Logistics Campus

Jira connection for the browser extension

Jira instance

The campus calls /rest/api/3 of this Jira directly from your browser. Credentials are stored locally in chrome.storage.local and never leave this browser.

Jira Cloud (…atlassian.net) and self-hosted Jira (Server/Data Center) are supported.

Create an Atlassian API token at id.atlassian.com → Security → API tokens. For Jira Data Center use a personal access token. Prefer a token with the smallest possible scope.

Defaults

Maps Jira workflow statuses onto campus lanes. Targets must be one of: To Do, In Progress, In Review, In Testing, Release, Released.

Everything else (label, project key, poll interval, quantity field) is configured in the campus sidebar. The campus starts in mock mode until a Jira instance is configured here.

This page is the only place where credentials are entered. Remove them any time with Reset.
